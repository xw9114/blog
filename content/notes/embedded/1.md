## 协议核心特性对比

| **协议** | **物理引脚**                             | **通信方式** | **典型速率**                      | **特点**                                           |
| -------- | ---------------------------------------- | ------------ | --------------------------------- | -------------------------------------------------- |
| **SPI**  | SCK, MISO, MOSI, NSS                     | 同步、全双工 | 可达数十几 Mbps                   | 速度快，硬件结构简单，无寻址机制（用 NSS 选择）    |
| **I2C**  | SCL, SDA                                 | 同步、半双工 | Standard: 100 kbps Fast: 400 kbps | 连线少（2 根），支持多从机，硬件设计需拉高电阻     |
| **CAN**  | CAN_TX, CAN_RX (经收发器转 CAN_H, CAN_L) | 异步、半双工 | 最高 1 Mbps                       | 差分信号抗干扰，硬件仲裁与错误检测，适合远距离车载 |

## SPI 关键配置（HAL）

### 时序模式

- **CPOL (Clock Polarity)**: 0 = 空闲时低电平；1 = 空闲时高电平
- **CPHA (Clock Phase)**: 0 = 在第一个边沿采样；1 = 在第二个边沿采样

### 代码示例（主模式配置）

C

```
SPI_HandleTypeDef hspi1;
hspi1.Instance = SPI1;
hspi1.Init.Mode = SPI_MODE_MASTER;               // 主机模式
hspi1.Init.Direction = SPI_DIRECTION_2LINES;     // 双线全双工
hspi1.Init.DataSize = SPI_DATASIZE_8BIT;         // 8 位数据帧
hspi1.Init.CLKPolarity = SPI_POLARITY_LOW;       // CPOL = 0
hspi1.Init.CLKPhase = SPI_PHASE_1EDGE;           // CPHA = 0
hspi1.Init.NSS = SPI_NSS_SOFT;                   // 软件控制 NSS 引脚（推荐）
hspi1.Init.BaudRatePrescaler = SPI_BAUDRATEPRESCALER_16; // 波特率分频（源自 APB2/APB1）
hspi1.Init.FirstBit = SPI_FIRSTBIT_MSB;          // 高位在前
HAL_SPI_Init(&hspi1);
```

## I2C 关键配置（HAL）

### 模式与寻址

- **主模式**: 由 STM32 发起时钟信号与寻址
- **从机地址长度**: 支持 7 位（常用）和 10 位寻址

### 代码示例

C

```
I2C_HandleTypeDef hi2c1;
hi2c1.Instance = I2C1;
hi2c1.Init.ClockSpeed = 100000;                  // 100 kHz 标准模式
hi2c1.Init.DutyCycle = I2C_DUTYCYCLE_2;          // 占空比 1:1
hi2c1.Init.OwnAddress1 = 0x00;                   // 主机自身地址（做从机时有效）
hi2c1.Init.AddressingMode = I2C_ADDRESSINGMODE_7BIT; // 7 位寻址
hi2c1.Init.DualAddressMode = I2C_DUALADDRESS_DISABLE;
hi2c1.Init.GeneralCallMode = I2C_GENERALCALL_DISABLE;
hi2c1.Init.NoStretchMode = I2C_NOSTRETCH_DISABLE; // 允许时钟延长
HAL_I2C_Init(&hi2c1);
```

## CAN 关键配置（HAL）

### 位时序（Bit Timing）定义

- Nominal Bit Time = $1 \times T_q + \text{BS1} + \text{BS2}$
- 波特率 = $\frac{\text{CAN 挂载总线时钟 (APB1)}}{\text{Prescaler} \times (1 + \text{BS1} + \text{BS2})}$

### 代码示例与过滤器配置

C

```
CAN_HandleTypeDef hcan1;
// CAN 基础初始化
hcan1.Instance = CAN1;
hcan1.Init.Prescaler = 4;                        // 分频系数
hcan1.Init.Mode = CAN_MODE_NORMAL;               // 正常工作模式
hcan1.Init.SyncJumpWidth = CAN_SJW_1TQ;          // 重新同步跳跃宽度
hcan1.Init.TimeSeg1 = CAN_BS1_9TQ;               // 时间段 1 (BS1)
hcan1.Init.TimeSeg2 = CAN_BS2_4TQ;               // 时间段 2 (BS2)
hcan1.Init.TimeTriggeredMode = DISABLE;
hcan1.Init.AutoBusOff = ENABLE;                  // 离线自动恢复
hcan1.Init.AutoWakeUp = DISABLE;
hcan1.Init.AutoRetransmission = ENABLE;          // 错误自动重发
HAL_CAN_Init(&hcan1);

// CAN 过滤器配置（不滤除任何 ID 示例）
CAN_FilterTypeDef filter = {0};
filter.FilterBank = 0;                           // 过滤器组 0
filter.FilterMode = CAN_FILTERMODE_IDMASK;       // 掩码模式
filter.FilterScale = CAN_FILTERSCALE_32BIT;
filter.FilterIdHigh = 0x0000;
filter.FilterIdLow = 0x0000;
filter.FilterMaskIdHigh = 0x0000;                // 掩码为 0 代表不检查对应位
filter.FilterMaskIdLow = 0x0000;
filter.FilterFIFOAssignment = CAN_RX_FIFO0;      // 关联到 FIFO 0
filter.FilterActivation = ENABLE;
HAL_CAN_ConfigFilter(&hcan1, &filter);

// 必须手动开启 CAN 外设
HAL_CAN_Start(&hcan1);
// 开启 FIFO 0 消息挂起中断（如需使用中断接收）
HAL_CAN_ActivateNotification(&hcan1, CAN_IT_RX_FIFO0_MSG_PENDING);
```

## 注意点

- **SPI NSS 踩坑** — 使用硬件 `NSS` 自动控制时易出现多机冲突或时序不匹配，通常建议配置为 `SPI_NSS_SOFT`，并用普通 GPIO 软件拉低/拉高来实现准确的片选控制。
- **I2C 物理死锁** — I2C 偶尔因复位或干扰导致从机死锁（SDA 被拉低）。遇到此情况，可将 SCL 改为普通 GPIO，手动模拟输出 9 个时钟脉冲（Clock Out）以释放总线。
- **I2C 阻塞问题** — 标准 HAL 库的 `HAL_I2C_Mem_Write` 等普通函数为死等阻塞设计，在对实时性要求高的系统中容易卡死，建议复杂项目切换至 DMA 模式或硬件中断。
- **CAN 采样点计算** — 工业总线标准通常建议 CAN 采样点设置在 $75\% \sim 85\%$ 之间。通过调整 `BS1` 和 `BS2` 的比例可以改变采样点位置（采样点 = $\frac{1 + \text{BS1}}{1 + \text{BS1} + \text{BS2}}$）。
- **CAN 启动步骤** — 调用 `HAL_CAN_Init` 后，**必须**依次调用 `HAL_CAN_ConfigFilter` 和 `HAL_CAN_Start`，否则硬件将无法正常接收/发送报文。
